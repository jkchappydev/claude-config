# 주간 워크로그 회고

## 구조 원칙

- **일별 워크로그는 프로젝트 단위에서만** 존재한다(`docs/worklog/YYYY-MM-DD.md`). `~/.claude`(전역)에는 일별 워크로그를 두지 않는다.
- **전역 `~/.claude`는 여러 프로젝트의 일별 워크로그를 취합한 주간 워크로그만** 관리한다.

## 범위

- 이번 주 **월요일 ~ 일요일**의 `docs/worklog/YYYY-MM-DD.md`만 대상으로 한다.
- **현재 디렉터리가 `~/.claude`(전역)인 경우**: 사용자가 "통합"이라는 말을 하지 않아도 **항상 통합 모드**로 동작한다 — 전역에는 자체 일별 워크로그가 없으므로 단일 모드가 성립하지 않는다.
- **그 외(개별 프로젝트) 디렉터리인 경우**: 기본은 **현재 프로젝트**만 정리하고, "통합 회고", "여러 프로젝트" 요청 시에만 `~/.claude/references/worklog-projects.md`에 등록된 프로젝트를 함께 정리한다.

## 저장

- 개별 프로젝트에서 실행 시  
  `docs/worklog/weekly/YYYY-Www.md` (해당 프로젝트 안에 저장)
- 전역 `~/.claude`에서 실행 시(항상 통합 모드)  
  `~/.claude/worklog-weekly/YYYY-Www.md`

이번 주 워크로그가 없으면 없다고 알리고 종료한다.

## 작성 형식

```markdown
# YYYY-Www 주간보고 (YYYY-MM-DD ~ YYYY-MM-DD)

## 완료된 작업
- ...

## 진행 중 / 이슈
- [이슈명]&#58; 현재 상황 → 다음 액션

## 다음 주 예정
- ...
```

통합 보고는 각 항목 안에서 프로젝트별로 구분한다.

## 작성 원칙

- 날짜별 워크로그를 그대로 나열하지 않고 **중복을 제거해 핵심 작업 단위로 정리한다.**
- 완료된 작업은 **무엇을 했는지와 결과가 드러나게** 작성한다.
- 진행 중인 이슈는 **현재 상황과 다음 액션**을 함께 작성한다.
- 기존 `docs/worklog/YYYY-MM-DD.md` 파일은 수정하지 않는다.
